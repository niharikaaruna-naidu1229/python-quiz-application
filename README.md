# 🧠 Python Quiz Application

An interactive **Python & General Knowledge Quiz** designed to test basic knowledge through multiple-choice questions.

## 🚀 Live Demo

👉 **[Play the Python Quiz](https://niharikaaruna-naidu1229.github.io/PythonQuiz/)**

## 📌 About the Project

This project is a simple and interactive quiz application containing multiple-choice questions.

Users can:

* Answer quiz questions
* Select from multiple options
* Track their score
* Receive instant feedback
* View their final score at the end

## ✨ Features

* 🧠 Multiple-choice questions
* 📊 Real-time score tracking
* ✅ Correct answer feedback
* ❌ Wrong answer indication
* 🎯 Final score display
* 📱 Simple and responsive interface
* 🌐 Hosted using GitHub Pages

## 🛠️ Technologies Used

* **PYTHON**
* **HTML**
* **CSS**
* **JavaScript**

## 🎮 How to Use

1. Open the **Live Demo**.
2. Read each question carefully.
3. Select your answer.
4. Continue through all questions.
5. Check your final score at the end.


## 🎯 Project Objective

The main objective of this project is to create a simple web-based quiz application and practice basic concepts of **HTML, CSS, and JavaScript**, including user interaction, question handling, and score calculation.
